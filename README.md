# NexTrade AI 📈🤖

NexTrade AI is a smart stock prediction and visualization tool powered by AI and historical market data. It helps investors, analysts, and hobbyist traders make informed decisions through interactive charts and machine learning predictions.

## 🚀 Features

- 📊 Candlestick chart visualization with Plotly
- 📈 Historical stock data fetching via Yahoo Finance
- 🔮 Predictive analytics using machine learning (e.g., LSTM, linear regression, etc.)
- 📉 Customizable date range and stock ticker input
- 🧠 Easy to expand with sentiment analysis or news-based features
